# Windows route

Windows can't read your phone's texts directly. Phone Link can show messages, but it can't export them. Use one of these:

1. **M-PESA statement PDF (recommended):** request it from the M-PESA app or `*334#`. It arrives by email with a password sent by SMS. Open Pesadithi Lab in any browser and load the PDF.
2. **Android SMS backup:** make the `.xml` backup on your phone (see [Android route](../android)), copy it to your PC, and load it.

Everything runs in your browser on Windows. Nothing is installed.
